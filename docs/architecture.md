## نمای کلی

معماری پیشنهادی:
- Deck: مدیریت دسته کارت‌ها و شافل
- Player: کلاس بازیکن (دست، نوبت، امتیاز)
- TrumpManager: مدیریت حکم و اولویت کارت‌ها
- TrickManager: مدیریت هر دست (۱۳ دست)
- AIPlayer: هوش مصنوعی با استراتژی هیوریستیک
- CardRenderer: رندر کارت‌ها با انیمیشن
- ScoreBoard: نمایش امتیازها

## اصول طراحی

### ۱. جداسازی لایه‌ها (Separation of Concerns)
- لایه رابط کاربری فقط نمایش می‌دهد
- لایه منطق قوانین بازی را اجرا می‌کند
- لایه داده‌ها مدیریت ذخیره‌سازی را برعهده دارد

### ۲. ماژولار بودن (Modularity)
- هر کلاس یک مسئولیت مشخص دارد
- وابستگی‌ها به حداقل رسانده شده‌اند
- قابلیت تست هر ماژول به صورت مستقل

### ۳. الگوهای طراحی استفاده‌شده
- **MVC (Model-View-Controller):** جداسازی داده، نمایش و کنترل
- **Observer:** برای رویدادهای بازی
- **Factory:** برای ایجاد مهره‌ها/کارت‌ها/دشمنان
- **Strategy:** برای الگوریتم‌های AI مختلف

## نکات فنی مهم

1. **استفاده از Canvas به جای DOM:** برای کارایی بهتر در رندر
2. **Web Workers:** برای محاسبات سنگین AI (در صورت نیاز)
3. **RequestAnimationFrame:** برای رندر روان
4. **Event Delegation:** برای مدیریت بهتر رویدادها
